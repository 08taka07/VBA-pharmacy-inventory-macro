# 生成AIを活用した薬局在庫表作成マクロ

Excel VBAを使用して、元データの在庫数を集計し、
指定した商品について在庫一覧表を作成するためのサンプルです。

学会発表ポスターで紹介した作成手順に合わせ、
２枚のシートで使用できるようにしています。

## できること

- 元データから「商品名」と「在庫数」の列を探します。
- 同じ商品が複数行にある場合は、在庫数を合算します。
- 集計結果を「完成」シートに転記します。
- 商品が見つからない場合は「未発見」と表示します。
- 「完成」シートのA列が２行連続で空欄になったところで、
  転記を終了します。

## 準備するもの

- Windows版 Microsoft Excel
- 商品名と在庫数を含む元データ

## Excelの準備

1. Excelで新しいブックを開き、次の２枚のシートを作成します。
   - 元データ
   - 完成

2. 「元データ」シートに元データを貼り付けます。
   １行目に「商品名」と「在庫数」の見出しが必要です。

3. 「完成」シートを次のように準備します。
   - A1に「商品名」、B1に「在庫数」と入力
   - A2以降に、在庫数を確認したい商品名を入力
   - B2以降は空欄にする

## マクロの設定と実行

1. このリポジトリの `VBA-code_ポスター公開用.txt` を開き、
   コードをすべてコピーします。

2. Excelで `Alt` + `F11` を押し、VBA編集画面を開きます。

3. 対象のブックを選択し、
   「挿入」→「標準モジュール」を選びます。

4. 表示された画面にコードを貼り付けます。

5. Excelに戻り、ファイルを
   「Excel マクロ有効ブック（*.xlsm）」形式で保存します。

6. `Alt` + `F8` を押し、`CopyAndSumStock` を選んで実行します。

7. 「完成」シートの在庫数を元データと照合します。

## 動作の例

「元データ」に同じ商品が２行あり、それぞれの在庫数が
３と４の場合、「完成」シートには合計の７が表示されます。

## 使用時の注意

- 商品名の空白や全角・半角の違いを一部吸収して照合します。
- 在庫数が空欄またはマイナスの場合は、０として扱います。
- 在庫数が数値以外の場合は、処理前にメッセージを表示します。
- まず仮データで動作を確認し、集計結果を元データと照合してください。
